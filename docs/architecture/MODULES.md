## Details

### Vendor / Organization — `vendors`

**Responsibility:** Tenant root. Vendor (merchant business) lifecycle, profile, status, plan assignment, tenant settings.

- **Owns data:** `vendors`
- **API prefixes:** `/api/v1/vendors`, `/api/v1/vendor`
- **Depends on (sync calls):** none
- **Publishes events:** `vendor.created`, `vendor.updated`, `vendor.suspended`, `vendor.reactivated`
- **Consumes events:** `billing.subscription_changed`
- **Microservice extraction:** keep

### Identity & Access — `identity`

**Responsibility:** Authentication (password, tokens, refresh rotation, MFA later), roles, permissions, RBAC policy evaluation, API keys.

- **Owns data:** `roles`, `permissions`, `role_permissions`, `user_roles`, `refresh_tokens`, `user_tokens`
- **API prefixes:** `/api/v1/auth`, `/api/v1/me`, `/api/v1/roles`
- **Depends on (sync calls):** `vendors`
- **Publishes events:** `identity.login_succeeded`, `identity.login_failed`, `identity.role_changed`, `identity.session_revoked`
- **Consumes events:** `vendor.created`, `vendor.suspended`
- **Microservice extraction:** later

### User Management — `users`

**Responsibility:** User profiles and membership of a vendor (or platform staff), invitations, activation/deactivation.

- **Owns data:** `users`, `invitations`
- **API prefixes:** `/api/v1/users`, `/api/v1/invitations`
- **Depends on (sync calls):** `identity`, `vendors`
- **Publishes events:** `user.created`, `user.updated`, `user.deactivated`, `user.invited`
- **Consumes events:** `vendor.suspended`
- **Microservice extraction:** keep

### Categories — `categories`

**Responsibility:** Vendor-internal category tree and mapping targets for marketplace category taxonomies.

- **Owns data:** `categories`
- **API prefixes:** `/api/v1/categories`
- **Depends on (sync calls):** `vendors`
- **Publishes events:** `category.created`, `category.updated`, `category.deleted`
- **Consumes events:** none
- **Microservice extraction:** keep

### Attributes — `attributes`

**Responsibility:** Attribute definitions/schemas (size, colour, material...) and per-category attribute requirements incl. marketplace-specific mappings.

- **Owns data:** `attribute_definitions`, `attribute_values`, `category_attributes`, `product_attribute_values`
- **API prefixes:** `/api/v1/attributes`, `/api/v1/categories/:id/attributes`
- **Depends on (sync calls):** `categories`
- **Publishes events:** `attribute.updated`
- **Consumes events:** `category.deleted`
- **Microservice extraction:** keep

### Product Catalog — `catalog`

**Responsibility:** Canonical product + variant/SKU master data. The single source of truth for what a vendor sells, independent of any marketplace.

- **Owns data:** `products`, `product_variants`, `product_marketplace_data`, `data_jobs`
- **API prefixes:** `/api/v1/products`, `/api/v1/variants`, `/api/v1/data-jobs`
- **Depends on (sync calls):** `vendors`, `categories`, `attributes`
- **Publishes events:** `product.created`, `product.updated`, `product.archived`, `variant.created`, `variant.updated`, `variant.price_changed`
- **Consumes events:** `category.deleted`, `document.processed`
- **Microservice extraction:** later

### Documents & Media — `documents`

**Responsibility:** Product images/documents metadata, upload (pre-signed URLs), virus-scan/processing pipeline, object storage lifecycle.

- **Owns data:** `product_documents`
- **API prefixes:** `/api/v1/documents`, `/api/v1/products/:id/documents`
- **Depends on (sync calls):** `catalog`
- **Publishes events:** `document.uploaded`, `document.processed`, `document.deleted`
- **Consumes events:** `product.archived`
- **Microservice extraction:** later

### Warehouse — `warehouses`

**Responsibility:** Vendor fulfilment locations, addresses, default/priority routing and activation. Stock lives in inventory; a warehouse with stock cannot be removed.

- **Owns data:** `warehouses`
- **API prefixes:** `/api/v1/warehouses`
- **Depends on (sync calls):** `vendors`
- **Publishes events:** `warehouse.created`, `warehouse.updated`, `warehouse.deactivated`
- **Consumes events:** none
- **Microservice extraction:** keep

### Inventory — `inventory`

**Responsibility:** Stock per variant per warehouse (on hand / reserved / incoming / damaged / returned), the append-only movement ledger, reservations, adjustments, transfers and availability. Never changes a quantity without a movement.

- **Owns data:** `inventory`, `inventory_movements`, `inventory_reservations`, `stock_transfers`, `stock_transfer_items`, `vendor_counters`
- **API prefixes:** `/api/v1/inventory`
- **Depends on (sync calls):** `catalog`, `warehouses`
- **Publishes events:** `inventory.adjusted`, `inventory.reserved`, `inventory.released`, `inventory.low_stock`, `inventory.transferred`
- **Consumes events:** none
- **Microservice extraction:** early

### Marketplace Accounts — `marketplace-accounts`

**Responsibility:** A vendor's connection to a marketplace (seller account), authorization lifecycle, encrypted credential custody. Credentials never leave the backend.

- **Owns data:** `marketplace_accounts`, `marketplace_authorizations`
- **API prefixes:** `/api/v1/marketplace-accounts`
- **Depends on (sync calls):** `vendors`
- **Publishes events:** `marketplace_account.connected`, `marketplace_account.authorization_expired`, `marketplace_account.disconnected`, `marketplace_account.paused`
- **Consumes events:** `vendor.suspended`
- **Microservice extraction:** later

- **Owns data:** none
- **API prefixes:** `/api/v1/marketplaces`, `/api/v1/marketplace-accounts/:id/authorization-url`, `/api/v1/marketplace-accounts/:id/authorize`, `/api/v1/marketplace-accounts/:id/reconnect`, `/api/v1/marketplace-accounts/:id/refresh`, `/api/v1/marketplace-accounts/:id/health-check`, `/api/v1/marketplace-accounts/:id/disconnect`, `/api/v1/marketplace-accounts/:id/remote-products`

- **Microservice extraction:** early

### Listings & Channels — `listings`

- **Depends on (sync calls):** `catalog`, `marketplace-accounts`, `marketplace-connectors`, `inventory`, `sync`, `warehouses`

- **Owns data:** `orders`, `order_items`, `order_status_events`, `order_status_updates`

### Synchronization — `sync`

**Responsibility:** Async sync job engine: durable job rows (API -> job -> queue -> worker -> connector -> marketplace -> normalise -> DB -> sync log), idempotent enqueue, retries with exponential backoff, dead-lettering, progress, failure details, manual retry. Domain modules own their runners; this module owns the engine, history and scheduling.

- **Owns data:** `sync_jobs`, `sync_logs`
- **API prefixes:** `/api/v1/sync`
- **Depends on (sync calls):** `marketplace-accounts`, `marketplace-connectors`, `jobs`
- **Publishes events:** `sync.started`, `sync.completed`, `sync.failed`, `sync.dead_lettered`
- **Consumes events:** none
- **Microservice extraction:** early

### Webhooks — `webhooks`

- **Owns data:** `webhook_events`
- **API prefixes:** `/api/v1/webhooks`, `/api/v1/marketplace-accounts/:id/webhook-secret`, `/api/v1/marketplace-accounts/:id/webhook-config`
